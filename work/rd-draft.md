# 要求定義書 メモ(ドラフト)

元のPrompt全文: [rd-original-prompt.md](./rd-original-prompt.md)

## 1. 全体
- 2つのアプリを1つのシェルに収め、画面上部のトグルで切り替える(App1: 広告キャンペーンサイト / App2: 広告素材管理システム)。
- 認証なし(ログイン機能は実装しない)。
- 題材は共通で **Microsoft Surface Ultra**。
- 全体で2D/3D体験を提供し、レンダリング品質は最高品質とする。
- 秘密情報: Azure Speechキーは添付ファイル(`AzureSpeech.txt`)で提供。リポジトリにコミットしない。環境変数/Key Vault/サーバー側プロキシ経由で扱い、クライアントへ露出させない方針とする。

## 2. App1: 広告キャンペーンWebサイト
### 2.1 目的・ターゲット
- 一般コンシューマー向け Surface Ultra の価値説明と公式サイトへの誘導(CTA)。
- ターゲット: いつでもどこでもCopilotとPromptで、アプリ/Web/動画コンテンツ制作を楽しみたいクリエイター、ソフトウェアエンジニア。
- 訴求: 最強の没入感、最高のリッチなエクスペリエンス。

### 2.2 機能要件
1. 価値説明コンテンツ+公式サイトへの導線。
2. YouTubeのMicrosoft公式動画があれば埋め込み(なければ省略。公式チャンネルのみ対象)。
3. 利用シーン/ユースケース(クリエイター・ソフトウェアエンジニアの場面)の提示。
4. CGアニメーション、2D/3D体験(2D/3D表示の切替または併用)。
5. Azure Speechによるナレーション(再生/停止/言語別音声)。
6. 多言語: 日本語/英語/中国語/韓国語。ユーザーの言語(ブラウザ言語等)で初期表示し、言語切り替え機能を提供。
   - 認証なしのため「ログインユーザーの言語」はブラウザ/OSロケールで代替する(要確認)。
7. 情報の体系的構造化と関連付け:
   - 2D: ナビゲーションメニュー、滑らかに動的変化する画面内遷移で関係性を表現。
   - 3D: Surface Ultraのブランドイメージの空間を構築し、情報を空間配置で表現。
8. ペルソナ別の全画面プレゼンテーション機能(ペルソナごとに価値説明を切り替え)。
9. Surface Ultraのブランドイメージを厳守(トーン、色、タイポグラフィ、ロゴ使用規定)。

### 2.3 非機能
- 高品質レンダリング(高解像度、アンチエイリアス、高品質アセット)。ただし低性能端末向けにフォールバックを用意するか要検討。
- アクセシビリティ(字幕/トランスクリプト、キーボード操作、reduced-motion対応)。

## 3. App2: 広告コンテンツ素材管理システム
### 3.1 前提
- ダミー組織: Microsoft Advertizing Tokyo - 畠山支店(広告代理店)。
- コンテンツ素材はSurface Ultra関連。YouTubeや公式サイトから取得。不足分(画像/動画)は後日ユーザーが提供。
- データはダミー/シード。

### 3.2 業務フロー(ビジネスエンティティ)
広告企画 → 予算見積もり → 制作(外部発注含む) → マルチチャネル展開 → 展開後の利用状況(KPI設定済みの顧客サイト誘導など)
- 主なエンティティ(案): 顧客、キャンペーン、企画、見積、予算、制作プロジェクト、外部発注先/発注、成果物(素材)、チャネル、展開、KPI/OKR、利用状況。
- 各エンティティの関連を2D/3Dで可視化(2D: グラフ/関係図/ダッシュボード、3D: 空間上のノードと関連)。

### 3.3 機能要件
1. 制作プロジェクトごとの進捗状況、予算消化状況、成果物、KPIの可視化。
2. 企画・見積・制作途中の変更を許容(バージョン管理/変更履歴)。
3. 変更に応じたKPI/OKRのシミュレーション(what-if)。
4. 素材管理(登録、メタデータ、プレビュー、チャネル紐付け)。
5. 外部発注の管理(発注先、金額、納期、状態)。

### 3.4 デザイン
- Microsoft Designのベストプラクティス(Fluent Design)に基づく、モダンで落ち着いたデザイン。

## 3.5 カメラワーク選択機能(両アプリ共通)
2D/3D UIおよびペルソナ別プレゼンテーションで、カメラワークをユーザーが選べる。元の分類は [rd-original-prompt.md](./rd-original-prompt.md) の「追加Prompt 1」を参照。

### 要件
- 専門用語を画面に出さず、「何がどう変わるか」が分かる平易な言葉で表示する(英語の専門名は詳細/ツールチップに留める)。多言語(日/英/中/韓)対応。
- 選択すると即プレビューに反映される。各選択肢に短い動くサムネイル/ミニプレビューを付ける。
- 2段階の選び方:
  1. **かんたん選択(プリセット)**: 雰囲気のスライダー「落ち着き ↔ 派手」。
  2. **くわしく選択(任意)**: 4要素を個別に変更。
- 適用範囲: 3D空間の視点移動、2Dのズーム/パン/画面遷移の動き、プレゼンテーションの場面転換。
- 既定値: 落ち着いたプリセット。「動きを減らす」(reduced-motion)設定時は静止/ごく弱い動きを強制。
- 3Dは実カメラ操作として実装、2Dは同等の動きをCSS/アニメーションで近似する。

### かんたん選択(プリセット案: 落ち着き → 派手の順)
| 画面表示(案) | 何が変わるか | 元の分類 |
|---|---|---|
| じっくり説明 | ほぼ動かず、ゆっくり近づく。内容に集中できる | Corporate / Keynote |
| 製品をきれいに見せる | 製品の周りをゆっくり回り、細部に寄る | Product / Tech Keynote |
| 映画のように | ゆっくり寄り、少し自然な揺れ | Cinematic |
| その場にいる感じ | 手持ちのような揺れで、被写体を追う | Documentary |
| テンポよく見せる | 寄り・引き・切り替えが速い | YouTube |
| 広告らしく印象的に | 近づく→大きく引く、勢いのある動き | Commercial |
| 非現実的な視点 | 360度回り込み、突き抜けるような動き | Anime / Stylized 3D |
| 音楽に合わせて激しく | 高速で回転・急ズーム | Music Video |
| 迫力のゲーム風 | 空間を飛び抜ける超高速移動 | Game Trailer / FPV |

### くわしく選択(画面文言案)
- **大きさ(Shot Size)**: 「世界全体を見せる」(EWS)/「周りも含めて見せる」(WS)/「全体を見せる」(FS)/「説明に集中」(MS/MCU)/「ディテールを強調」(CU)/「ロゴや質感の一点だけ」(ECU)
- **角度(Angle)**: 「自然で信頼感」(Eye Level)/「力強く見せる」(Low)/「全体を把握」(High)/「真上から配置を見せる」(Bird's Eye)/「巨大に見せる」(Worm's Eye)/「傾けてスピード感」(Dutch)/「自分の視点で」(POV)
- **動き(Movement)**: 「動かない」(Static)/「ゆっくり近づく」(Push In)/「ゆっくり離れる」(Pull Out)/「左右に振る」(Pan)/「上下に振る」(Tilt)/「横に並走」(Tracking)/「周りを回る」(Orbit)/「大きく昇降」(Crane)/「手持ち風」(Handheld)/「滑らかに追う」(Gimbal)/「一気に振る」(Whip Pan)/「ズーム」(Zoom)/「空間を飛び抜ける」(Fly-through)/「画面を回転」(Roll)
- **動きの性格(Character)**: 「完全に静止」(Locked)/「とてもゆっくり」(Slow)/「滑らか」(Smooth)/「ふわっと浮遊」(Floating)/「人が操作した自然な揺れ」(Natural)/「テンポよく」(Energetic)/「キビキビ」(Snappy)/「激しく」(Aggressive)/「超高速」(Hyperdynamic)/「現実にはありえない動き」(Impossible)

### 表記
- 内部では `[Shot Size] + [Angle] + [Movement] + [Motion Character]` で保持(例: `Close-Up + Low Angle + Slow Orbit + Floating`)。選択変更時、画面に「いま: 製品に寄って、力強く見せながら、ゆっくり周りを回ります」のような一文を表示する。
- 既定の組み合わせ(例): Keynote=`Medium Wide + Eye Level + Slow Dolly In + Smooth`、Premium Product=`Close-Up + Low Angle + Slow Orbit + Floating`。
- 技術的に2Dで不可能な組み合わせはグレーアウトし、理由を表示する。

## 4. 想定技術(案・未確定)
- フロントエンド: React + TypeScript、Fluent UI、3Dは three.js / React Three Fiber、アニメーションは Framer Motion 等。
- Azure Speech: Speech SDK(トークン発行用の軽量バックエンド経由)。
- ホスティング: Azure Static Web Apps など。データはモックJSONから開始。

## 5. 未確定事項/要確認
- 「ログインユーザーの言語」の扱い(認証なしのためブラウザ言語で代替でよいか)。
- Surface Ultraの公式情報・ブランドガイドライン・画像/動画素材の入手方法と利用許諾(架空/未発表製品の可能性、仕様の出典)。
- CGアニメーション/3Dモデルの制作手段(生成 or 提供)。
- 対応ブラウザ/端末と最高品質レンダリングの性能基準。
- 初期データ量とKPI/OKRシミュレーションのロジック詳細。
- ナレーションの音声/声質、台本の作成方法(多言語)。
- カメラワークのプリセット名・文言の確定、および設定の保存先(ブラウザのローカル保存で足りるか)。
