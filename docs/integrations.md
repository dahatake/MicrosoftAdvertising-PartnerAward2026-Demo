# 外部連携カタログ

このアプリが API・ファイル・DB・イベントなどで行う、外部のアプリ・データとの連携を、1 連携 1 項目で記録します。外部連携がないアプリは、このファイルを使わなくてかまいません（任意です）。
追加・変更・廃止は rd-author だけが行い、変更は要求定義書の変更履歴に記録します。ID は `python scripts/next-id.py INT` でだけ採番します。検査は `python scripts/verify.py --docs-only` です。

## 書式

見出しは `#### INT-001 <名前>` の形式で、その下に「欄名: 値」の箇条書きを書きます。

- 必ず値を書く欄: 連携先、方向（受信／送信／双方向）、方式、データ分類、個人情報（あり／なし）、認証認可、責任分界、状態（検討中／運用中／廃止）、関連する要求（FR-xxx、NFR-xxx-xxx）
- 次の欄は、値、`なし`、`TBD（Q-xxx）`（質問票の ID）のどれかで必ず埋めます: 頻度と量、可用性・SLA、レート制限、エラー・再試行・冪等性、契約・バージョン、変更通知、監視、データ保持、障害時の代替、法務・ライセンス
- 認証情報の値（トークン・パスワード・鍵・接続文字列）は、この文書に書きません。認証認可の欄には方式の名前を、「秘密の保管場所」の欄には保管場所の名前（例: Key Vault の名前）だけを書きます。値らしい文字列は検査が違反として報告します。
- チェックリストは `.github/skills/requirement-definition/integration-checklist.md` にあります。

  ```text
  #### INT-001 受注 API（例。実在する連携ではありません）
  - 連携先: 取引先 A の受注システム
  - 方向: 受信
  - 方式: REST（HTTPS）
  - データ分類: 取引データ（社外秘）
  - 個人情報: あり
  - 認証認可: OAuth 2.0 クライアントクレデンシャル
  - 秘密の保管場所: Key Vault（名前は運用手順書に記載）
  - 責任分界: 取引先 A が受注データの正確性、当社が受信後の保管と処理に責任を持つ
  - 状態: 検討中
  - 関連する要求: FR-012
  - 頻度と量: TBD（Q-010）
  - 可用性・SLA: なし
  - レート制限: なし
  - エラー・再試行・冪等性: なし
  - 契約・バージョン: なし
  - 変更通知: なし
  - 監視: なし
  - データ保持: なし
  - 障害時の代替: なし
  - 法務・ライセンス: なし
  ```

## 項目

#### INT-001 Azure Speech トークン発行
- 連携先: Azure AI Speech（トークン発行 REST）
- 方向: 送信
- 方式: REST（HTTPS）。軽量 Node バックエンド経由
- データ分類: ナレーションの台本テキスト（公開情報）
- 個人情報: なし
- 認証認可: サブスクリプションキーで短期トークンを取得し、クライアントにはトークンだけを渡す
- 秘密の保管場所: バックエンドの環境変数（名前は実装時に決める）
- 責任分界: キーの管理と契約は利用者、サービスの提供は提供元
- 状態: 検討中
- 関連する要求: FR-006、FR-007、NFR-SEC-001
- 頻度と量: {PARAM-005} の有効期間ごとに 1 回程度。上限は {PARAM-008}
- 可用性・SLA: なし
- レート制限: {PARAM-008}（自システム側の上限）
- エラー・再試行・冪等性: 503・429 を返し、クライアントはフォールバックする（FR-006）
- 契約・バージョン: なし
- 変更通知: なし
- 監視: キーをログに出さない（NFR-SEC-001）
- データ保持: なし（保存しない）
- 障害時の代替: ブラウザの音声合成（SpeechSynthesis）
- 法務・ライセンス: 利用者が契約済みのキーを使う。新規契約はしない

#### INT-002 公式 YouTube 動画の埋め込み
- 連携先: YouTube（公式チャンネルの動画。既定は {PARAM-010}）
- 方向: 受信
- 方式: iframe 埋め込み（読み取り専用。外部への書き込みなし）
- データ分類: 公開動画。利用者のブラウザから第三者へ通信が発生し、IP・Cookie が渡りうる
- 個人情報: 自システムは送らない（ブラウザ経由で IP・Cookie が第三者に渡る可能性は未確認）
- 認証認可: なし
- 秘密の保管場所: なし
- 責任分界: 動画の提供は YouTube、埋め込み先 URL の管理は利用者
- 状態: 検討中
- 関連する要求: FR-003
- 頻度と量: 画面表示ごとに 1 動画
- 可用性・SLA: 外部確認未実施。非公開・削除・オフライン時は視聴できない
- レート制限: なし
- エラー・再試行・冪等性: 読み込み失敗時の代替は未決（10.4 X-02a）
- 契約・バージョン: 外部確認未実施
- 変更通知: なし
- 監視: なし
- データ保持: 保存しない
- 障害時の代替: 未決（環境変数を空にすれば節を表示しない）
- 法務・ライセンス: 利用規約は外部確認未実施（10.4 X-02a）

#### INT-003 実広告素材（YouTube・TikTok）の参照
- 連携先: YouTube・TikTok の公開動画（Microsoft の公式チャンネル。具体的な動画は PARAM-018・019。Q-005 回答済み）
- 方向: 受信
- 方式: 公開 URL・埋め込み・サムネイルの参照のみ（読み取り専用。外部への書き込みなし。表示方法は Q-007 A。再生前の第三者通信はサムネイル画像の取得だけ。AC-115）
- データ分類: 公開動画。埋め込み時は第三者へ IP・Cookie が渡りうる
- 個人情報: 自システムは送らない（第三者への通信は未確認）
- 認証認可: なし
- 秘密の保管場所: なし
- 責任分界: 動画の提供は YouTube・TikTok、URL の管理は利用者
- 状態: 運用中
- 関連する要求: FR-027
- 頻度と量: 素材一覧の表示ごと。件数は PARAM-018・019（Q-005 回答済み）
- 可用性・SLA: 外部確認未実施（SLA は確認できていない）。非公開・削除・オフライン時は表示できない。代替は AC-114
- レート制限: 外部確認未実施。自システムは取得を一覧の表示時に限り、再生前はサムネイル画像の取得のみ（AC-115）
- エラー・再試行・冪等性: 読み込み失敗時は仮置き表示と元 URL のリンク（AC-114）
- 契約・バージョン: 外部確認未実施
- 変更通知: 対象外（受信のみの公開 URL 参照で、提供元からの通知を受ける契約がない）
- 監視: 対象外（読み取り専用のデモで、外部の稼働監視は設けない。失敗は AC-114 の代替表示で利用者に分かる）
- データ保持: 保存しない（動画・画像ファイルを複製しない。AC-112）
- 障害時の代替: 仮置き表示（AC-040）と元 URL のリンク
- 法務・ライセンス: 権利許諾は依頼者の申告（SRC-011）。証跡と各社の利用規約は外部確認未実施（10.4 X-08）
